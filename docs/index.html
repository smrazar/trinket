01 / In one minute

Watch it work.

A folder of photos, a document and a video — dropped in as one archive, planned, renamed, and run. No narration, no cuts, nothing sped up. That is the whole app.

02 / Nothing to set up

It already knows what you probably want.

Smaller, a friendlier format, and safe to send — the three things anyone actually wants from a file. trinket ships with defaults that deliver all three, so the common case needs no configuration at all. Every control is still there when you want it, one click into the plan.

03 / Drop it

The app proposes a plan.

Files land and trinket reads them, works out what it would do, and shows the whole path at once — open the archive, shrink the photos, convert the video, pack it back up. Every decision already answered. Change what you like, press one button.

04 / See what it carries

A scrub nobody can verify is just a promise.

Photos carry more than they look like they carry: coordinates, the camera's serial, the software, sometimes the machine that edited them. A cropped photo can keep a thumbnail of the uncropped original — so cropping someone out and sharing it leaks them anyway. trinket shows what it found, on a map, before removing anything.

05 / A different verb

"I zipped my photos and it got bigger."

Because JPEG, MP4 and PDF have no redundancy left. Zipping them adds container overhead — 145.3 MB came out at 146.7 MB, slowly. Compressing harder only makes it slower. So trinket opens the archive, re-encodes what is inside, and packs it back up. Same photos: 73.8 MB.

06 / Never a bar that lies

It tells you what it could not do.

A file trinket cannot improve is named and marked, never given a progress bar that never moves. A batch that saved nothing says so rather than printing 0%. macOS re-injects a producer name into every PDF it writes, so the strongest scrub cannot fully clean one — and the app says that where you choose it.

Install

Three lines.

$ git clone https://github.com/smrazar/trinket.git
$ cd trinket
$ ./install.sh

Builds with the Swift toolchain from the Command Line Tools. No Xcode. The app is ad-hoc signed, so a downloaded build is blocked by Gatekeeper unless you clear it by hand — building from the clone avoids that entirely. Bundles ffmpeg, which is why trinket is GPL-3.
